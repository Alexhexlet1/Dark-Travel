# Dark Travel

Dark Travel — это мрачная текстовая RPG в стиле dark fantasy, созданная для оттачивания навыков программирования на JavaScript.
Игрок отправляется в путешествие по гибнущему магическому миру, полному смертоносных аномалий, древних руин и опасных тварей. Пройти дальше и выжить здесь с помощью обычного меча не удастся — единственным оружием героя становится магия искажения реальности. Каждая загадка, запертая дверь или ритуал в игре — это реальные строки кода на JS, которые игроку предстоит написать или исправить самостоятельно.
Начните с базовых заклинаний-переменных и подчините себе древние циклы и функции, чтобы выбраться из тьмы.

Дальнейшее развитие проекта планируется на движке Phaser.
